One excuse from a home Wi-Fi router for dropping the connection at the exact moment a movie reaches its climax: it didn't drop the connection — it paused it itself, because the plot twist was so good even its firmware needed a minute to process it.

> I didn't drop the connection — I paused it myself. The plot twist was so good even my firmware needed a minute to process it.

## How it works

`main.py` (Python 3 standard library only) writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
